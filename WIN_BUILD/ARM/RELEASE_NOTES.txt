## System Requirements
- Windows 11 ARM64 (recommended)
- Windows 10 ARM64 (version 1903 or later)
- ARM64 processor (Qualcomm Snapdragon, Microsoft SQ series)
- 4GB RAM minimum (8GB recommended)
- 500MB available disk space

## Installation
1. Download the Echelon_ARM64_Setup.exe installer
2. Run the installer as Administrator
3. Follow the installation wizard
4. Launch Echelon from your Start Menu or Desktop shortcut

## Known Issues
- None at this time

## Technical Notes
- This build is specifically compiled for Windows ARM64 architecture
- For Intel/AMD 64-bit Windows systems, please use the standard Windows installer
- ARM64 builds provide optimized performance on ARM-based Windows devices
